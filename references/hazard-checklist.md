# 常见Hazard清单 · 按产品类型

> 写风险管理报告时，对照这个清单查有没有漏项。

---

## 通用Hazard（所有产品都要考虑）

| 类别 | 常见Hazard | 可能的伤害 |
|------|-----------|-----------|
| 能量危害 | 电能 | 电击、烧伤、心脏骤停 |
| 能量危害 | 热能 | 烫伤、火灾 |
| 能量危害 | 机械能 | 挤压、剪切、刺穿、坠落 |
| 能量危害 | 辐射 | 电离辐射伤害、紫外线伤害 |
| 能量危害 | 噪音 | 听力损伤 |
| 生物学危害 | 微生物 | 感染、交叉污染 |
| 生物学危害 | 化学物质 | 中毒、过敏、刺激、致癌 |
| 生物学危害 | 生物相容性 | 细胞毒性、致敏、溶血 |
| 操作危害 | 误操作 | 错误治疗、误诊 |
| 操作危害 | 标记错误 | 用错产品、用错规格 |
| 操作危害 | 说明书不清 | 操作错误 |
| 信息危害 | 数据错误 | 误诊、错误治疗 |
| 信息危害 | 软件故障 | 系统崩溃、数据丢失 |
| 信息危害 | 网络安全 | 数据泄露、被攻击 |
| 环境危害 | 储存条件 | 产品失效、变质 |
| 环境危害 | 运输损坏 | 产品故障 |
| 环境危害 | 处置不当 | 环境污染、交叉感染 |

## 按产品类型的特殊Hazard

### 骨科器械（植入物）

| Hazard | 可能的伤害 |
|--------|-----------|
| 材料断裂 | 二次手术、骨折不愈合 |
| 腐蚀 | 金属离子释放、过敏 |
| 磨损 | 磨损颗粒、骨溶解 |
| 感染 | 骨髓炎、植入失败 |
| 尺寸不匹配 | 复位不良、功能障碍 |
| 固定不牢 | 移位、骨折不愈合 |
| 骨吸收 | 应力遮挡、骨质疏松 |
| 无菌性松动 | 植入失败 |

### 电子/电气设备（监护仪、电刀等）

| Hazard | 可能的伤害 |
|--------|-----------|
| 漏电 | 电击 |
| 电池过热 | 烧伤、爆炸 |
| 报警失效 | 延误救治 |
| 数据错误 | 误诊、错误治疗 |
| 电磁干扰 | 设备故障、影响其他设备 |
| 软件死机 | 监护中断 |
| 电极烫伤 | 皮肤烧伤 |

### 无菌产品

| Hazard | 可能的伤害 |
|--------|-----------|
| 灭菌不彻底 | 感染 |
| 无菌包装破损 | 污染 |
| 货架期失效 | 产品变质、感染 |
| 灭菌残留 | 化学刺激、过敏 |
| 重复使用 | 交叉感染（一次性产品） |

### 软件/SaMD

| Hazard | 可能的伤害 |
|--------|-----------|
| 算法错误 | 误诊、漏诊 |
| 数据偏差 | 不公平诊断 |
| 网络攻击 | 数据泄露、系统瘫痪 |
| 版本更新故障 | 功能失效 |
| 人工过度依赖 | 医生不复核 |
| 可解释性不足 | 无法发现错误 |
| 训练数据不代表性 | 某些人群诊断不准 |

### 药物/生物制品组合产品

| Hazard | 可能的伤害 |
|--------|-----------|
| 药物剂量错误 | 过量、疗效不足 |
| 药物污染 | 感染、过敏 |
| 药物相互作用 | 不良反应 |
| 储存温度不当 | 药物失效 |

## 风险可接受准则参考

| 伤害严重程度 | 发生概率 | 风险等级 | 是否可接受 |
|------------|---------|---------|-----------|
| 严重（死亡/永久伤害） | 极低 | 高 | 必须控制 |
| 严重 | 很低 | 中 | 尽可能降低 |
| 中等（可逆伤害） | 低 | 中 | 尽可能降低 |
| 中等 | 高 | 高 | 必须控制 |
| 轻微 | 低 | 低 | 可接受 |
| 轻微 | 中 | 低 | 可接受 |

> 注意：每个公司的风险可接受准则可以不一样，但必须在风险管理计划里明确写出来。
