## 这是什么？

风险管理是医疗器械注册里最容易被发补的环节之一。很多人写的风险管理报告：hazard列不全、风险可接受准则不明确、风险控制措施写得很笼统。

这个Skill帮你：
- 搭风险管理报告的完整框架
- 列常见hazard清单
- 告诉审评员会挑哪些毛病
